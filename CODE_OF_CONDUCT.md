# Code of conduct

Keep discussions useful and respectful. English and Russian contributions are welcome.

- Discuss the code and behavior; avoid personal attacks, harassment and discrimination.
- Respect people's privacy. Do not post anyone's account information or authentication data.
- Do not use Issues or Pull Requests for spam, credential collection, or unsolicited invitation requests.
- Use reproducible examples and allow others time to respond.

The maintainer may edit or remove content, close discussions, or restrict participation when these rules are violated. For private security or credential-exposure reports, use the channel in [SECURITY.md](SECURITY.md). Other conduct concerns can be raised with the maintainer in an existing project discussion without repeating private or abusive material.
