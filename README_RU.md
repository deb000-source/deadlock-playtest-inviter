# Deadlock Playtest Inviter

Программа отправляет приглашение другу в плейтест Deadlock через твой Steam-аккаунт. Скачивать и запускать Deadlock не нужно. Всё работает на твоём компьютере; отдельного сервиса выдачи приглашений нет.

[English](README.md) · [Скачать](https://github.com/deb000-source/deadlock-playtest-inviter/releases) · [Сообщить об ошибке](https://github.com/deb000-source/deadlock-playtest-inviter/issues/new/choose)

## Что нужно

- Windows 10/11, **64-битный процессор Intel/AMD** — для готового EXE (Windows amd64).
- Твой Steam-аккаунт с доступом к Deadlock и возможностью приглашать друзей.
- SteamID64 друга или его числовой Steam AccountID / код друга.
- Официальное мобильное приложение Steam со Steam Guard — для входа по QR.

Программа использует уже доступную аккаунту возможность приглашать друзей. Ограничения Steam по дружбе, аккаунту и количеству приглашений сохраняются. Проект неофициальный и не связан с Valve.

## Скачать и запустить

1. Открой [Releases](https://github.com/deb000-source/deadlock-playtest-inviter/releases) и скачай **`deadlock-inviter-windows-amd64.exe`** из раздела **Assets** последнего релиза. Архив **Source code** нужен для самостоятельной сборки. Если релиза ещё нет, см. [сборку из исходников](#сборка-из-исходников).
2. Положи EXE в отдельную папку и открой в ней PowerShell. **Для готового EXE не нужны ни Go, ни установленный Deadlock.**
3. Замени `STEAM_ID_ДРУГА` на числовой Steam ID нужного друга и выполни:

```powershell
.\deadlock-inviter-windows-amd64.exe --auth qr STEAM_ID_ДРУГА
```

4. Откроется изображение QR. Отсканируй его в **официальном приложении Steam → Steam Guard**. Перед подтверждением проверь аккаунт и название устройства **Deadlock Inviter (QR)**.
5. Дождись ответа в PowerShell. После одной заявки программа завершится.

`Success` / код `0` означает, что Game Coordinator принял запрос. Друг может проверить [приглашения в плейтесты Steam](https://store.steampowered.com/account/playtestinvites). Сам ответ не подтверждает доставку и не задаёт срок её ожидания.

EXE не имеет цифровой подписи. Скачивай его из релизов этого репозитория; перед входом в Steam проверь источник, контрольную сумму и при необходимости исходники.

### Проверить скачанный файл

Скачай `SHA256SUMS.txt` из того же релиза и сравни указанную для EXE сумму с результатом:

```powershell
Get-FileHash .\deadlock-inviter-windows-amd64.exe -Algorithm SHA256
```

Совпадение помогает обнаружить повреждённый или отличающийся файл, но не заменяет цифровую подпись издателя. В релизе также будут лицензия проекта и тексты лицензий зависимостей.

## Способы входа и настройки

| Команда / параметр | Действие |
| --- | --- |
| `--auth qr` | Войти заново через QR в Steam Guard. |
| `--auth credentials` | Ввести логин и пароль, затем пройти Steam Guard, если он потребуется. Ввод пароля и кода скрыт. |
| `--auth auto` | По умолчанию: попробовать сохранённую сессию, иначе предложить способ входа. |
| `--auth cache` | Использовать только сохранённую сессию; если её нет, завершиться с ошибкой. |
| `--username ЛОГИН` | Указать логин для входа по паролю; также проверить владельца сохранённой сессии. |
| `--cache-session=false` | Не читать и не сохранять кеш сессии в этом запуске. |
| `--logout` | Удалить локальную сохранённую сессию и выйти; ID друга не нужен. |
| `--version`, `--help` | Показать версию или справку. |

**Параметры указываются перед ID друга.** Примеры:

```powershell
# Использовать сохранённую сессию или выбрать способ входа
.\deadlock-inviter-windows-amd64.exe STEAM_ID_ДРУГА

# Войти с паролем, введённым в консоли
.\deadlock-inviter-windows-amd64.exe --auth credentials --username ТВОЙ_ЛОГИН STEAM_ID_ДРУГА

# QR-вход без чтения и сохранения сессии
.\deadlock-inviter-windows-amd64.exe --auth qr --cache-session=false STEAM_ID_ДРУГА

# Удалить сохранённую сессию
.\deadlock-inviter-windows-amd64.exe --logout
```

В Windows токен, принятый Steam CM, может сохраняться в `%APPDATA%\deadlock-inviter\session.dpapi`. Он зашифрован Windows DPAPI для текущего пользователя Windows. Если Steam отклонит кешированный токен при автоматическом входе, программа предложит войти заново. DPAPI не защищает от вредоносного ПО, работающего от имени того же пользователя.

`--logout` удаляет только локальный файл. Сессию на серверах Valve эта команда **не отзывает**. При необходимости отзови её через настройки безопасности Steam.

## Необязательный файл настроек

Без `.env` программа тоже работает. Чтобы сохранить значения по умолчанию, скопируй [.env.example](.env.example) в `.env` в папке, из которой запускаешь команду:

```dotenv
AUTH_METHOD=auto
STEAM_USERNAME=
CACHE_SESSION=true
```

Приоритет: параметры команды → переменные окружения → `.env` → значения по умолчанию. `STEAM_PASSWORD` поддерживается в окружении и `.env`, но хранить пароль открытым текстом нежелательно. Оставь его незаданным — программа запросит пароль скрытым вводом. Коды Steam Guard сохранять не нужно. Необязательное недокументированное поле `DEADLOCK_LOCATION` обычно следует оставлять пустым.

Не публикуй `.env`, токены, файлы сессии и действующие QR-коды. Для приватного сообщения об уязвимости см. [SECURITY.md](SECURITY.md).

## Ответы и возможные ошибки

| Код | Значение |
| --- | --- |
| `0 Success` | GC принял запрос. Попроси друга проверить Steam. |
| `3 InvalidFriend` | Получатель не подходит для приглашения или отсутствует в друзьях. |
| `4 NotFriendsLongEnough` | Не выполнено требование Steam к сроку дружбы. |
| `5 AlreadyHasGame` | У друга уже есть доступ. |
| `6 LimitedUser` | Действуют ограничения аккаунта. |
| `7 InviteLimitReached` | Достигнут лимит приглашений. |

Другие коды выводятся как ошибки. Valve может менять интерфейс и ответы.

- **Окно сразу закрылось:** запускай команду из PowerShell, а не двойным щелчком по EXE.
- **QR не открылся:** открой локальный файл по пути, указанному в терминале. Не пересылай его. Если код обновился, сканируй новый.
- **Время входа истекло:** запусти программу снова и пройди Steam Guard в пределах тайм-аута авторизации — пяти минут.
- **Steam / GC не отвечает:** проверь соединение и попробуй позже. Если запрос мог уже уйти, сначала уточни у друга, пришло ли приглашение.
- **Не работает сохранённый вход:** используй `--auth qr` или удали кеш командой `--logout`.

## Сборка из исходников

Установи [Go 1.27.2 или новее](https://go.dev/dl/), скачай исходники или клонируй репозиторий и открой PowerShell в папке проекта:

```powershell
go mod download
go mod verify
go test -mod=readonly ./...
.\build.ps1
```

Готовая локальная сборка — `dist\deadlock-inviter.exe`. В `dist` также появятся файлы лицензий и `SHA256SUMS.txt`. Зависимости зафиксированы в `go.mod` и `go.sum`; обычная сборка не должна их менять. При обновлении зависимостей проверяй изменения обоих файлов вместе.

При сборке исходников на Linux/macOS постоянный кеш сессии отключён. Готовые релизы предназначены для Windows amd64; проверки релиза не включают запуск программы в Linux/macOS.
